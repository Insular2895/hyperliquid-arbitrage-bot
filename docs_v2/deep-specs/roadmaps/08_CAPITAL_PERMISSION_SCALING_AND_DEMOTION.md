## Capital law

```text
requested q
≤ available balance
∩ available book capacity
∩ Risk maximum
∩ future inventory capacity
∩ model/execution support
∩ Q_validated
∩ CapabilityManifest scope
```

Capital balance is not a term that can widen these limits. If no q satisfies every gate, `q*=0`.

## Permission classes

| Class | Meaning |
|---|---|
| None | No strategy effect; observe/replay/simulate/shadow only |
| Probe | Minimal, bounded, predeclared intervention to measure reality |
| Validated bounded | Exact market/mode/q/model/infra scope has M4/M5 evidence |
| Scaled validated | A wider/deeper exact scope has separately passed evidence gates |

## Scaling hierarchy

1. **Horizontal:** more genuinely independent validated opportunities, with shared constraints/correlation checked.
2. **Vertical:** larger q on an existing route only as `Q_validated` expands.
3. **Market/strategy/maker:** repeat all changed-scope evidence.
4. **Capital relocation:** Bridge separately validates destination versus STAY.
5. **Infrastructure:** host/feed/runtime promotion needs robust attributable economic value.

Horizontal-first is a project heuristic, not an unconditional theorem. Evidence can justify another order. Surplus capital may remain idle.

## Probe is not size validation

The source's `€40–50` example illustrates a measurement probe only. Actual probe q must satisfy current exchange minimums, Risk, inventory, book, preliminary support and experiment caps. Evidence at that q cannot authorize a different q.

## Demotion

`Q_validated` and M5 are dynamic. Prediction drift, fill/slippage/recovery degradation, unsupported tails, OOD, inventory/infra instability, security/state inconsistency or incident can shrink q or disable a scope immediately. Down-scale, fallback, revert and capital withdrawal are correct outcomes—not failures of project ambition.

Re-promotion requires current reconciliation, containment/fix or rollback, affected Replay/Shadow/Micro-live evidence and explicit approval. No cleared alert or profitable trade auto-promotes.
