# UNKNOWN, Cancel and Reconciliation Audit

Possible transmission means possible effect. Timeout is neither reject nor zero fill. Resolution queries stable identity, order, fills and balances; deduplicates fills; reconciles; then permits any new intent. Cancel sent is not canceled, and later fills remain real. Startup/crash/reconnect follow BOOTING → SYNCING → RECONCILING before READY. Exchange truth may correct local state, never the reverse.
