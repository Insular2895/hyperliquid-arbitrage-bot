# Domain Definition of Done Matrix

REBUILD IN PROGRESS

| Domain/capability | Definition of Done evidence |
|---|---|
| Graph/routes/OWA/Triangle | directed-side and continuity properties; exact comparator/cycle classification; topology invalidation; formula golden/parity; point-in-time Replay |
| Microstructure/formulas | authoritative formula/version/unit contract; boundary/invalid/rounding vectors; Rust/Python parity; no mixed-book versions |
| Participants/models | censor-aware point-in-time labels; walk-forward OOS; baseline, Brier/LogLoss/calibration/economics; OOD/fallback/drift |
| Simulator | deterministic mechanics, F0–F4 labeling, distribution calibration, branch/OOD boundaries, Micro-live predicted/actual comparison |
| Risk | every invariant has applicable unit/property/fault proof; deterministic decisions; rejects retained; kill/reset and config rollback drills |
| Execution | all reducer transitions, partial/zero/UNKNOWN/cancel race/recovery/crash/reconciliation scenarios; real fill calibration before M5 |
| Data | versioned schemas/IDs/units; immutable RAW; lineage; no lookahead; encode/decode/compatibility; reconstructible decision |
| Recorder/Replay | non-blocking priority/backpressure proof; checksums/quality; deterministic trace; incident window and retention proof |
| Inventory/capital/sizing | reconciled actuals/reservations; band/terminal viability; every q all-gates; Q_validated and allocation race properties; PnL attribution |
| Infrastructure | comparable B01–B12 distributions, clock validity, stability, Recorder penalty, safe degradation and economic upgrade/downgrade evidence |
| Deployment/security | verified immutable artifact; least privilege/secrets/redaction; safe startup/stop/update/rollback/migration; one owner; lifecycle fault proof |
| Operations/incidents | liveness/readiness semantics; actionable metrics/alerts; runbooks/drills; incident reconstruction; reviewed SLOs and revalidation triggers |

DoD means the scoped evidence package is complete and accepted. It never means all project capabilities share the same maturity.
