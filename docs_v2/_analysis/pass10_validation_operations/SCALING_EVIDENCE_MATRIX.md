# Scaling Evidence Matrix

DOCUMENTATION STATUS:
REBUILD IN PROGRESS

| Expansion | Evidence before promotion | Demotion signal |
|---|---|---|
| q1 → q2 → q3 vertical size | sufficient current-band actuals; next-band Simulator support; impact/tail/fill/Recovery/inventory calibration; Risk and operational stability | drift, tail underestimation, support loss or incident |
| new market/route | metadata/formula/Graph validity; Atlas/model support; Replay/Shadow; bounded Micro-live | exchange-rule change, poor liquidity/calibration |
| TT → MT/MTT | queue/fill/adverse-selection model, cancel-race and maker Recovery evidence | fill/calibration or resting-order safety failure |
| Bridge activation | all candidate paths plus STAY, terminal viability, relocation/exit economics and failure evidence | stranded capital, failed exit or reconciliation |
| more parallel opportunities | shared balance/book/asset/Risk capacity and reservation race tests | contention/double-counting or tail concentration |
| infrastructure upgrade | comparable benchmark, attributable economic LCB, stability, Shadow and required Micro-live | degraded tails/economics/host identity |
| capital increase | Q_validated support across size/portfolio/market plus explicit approval | Q_validated shrink or portfolio/Risk limit |

`Q_validated` is the largest quantity that passes every required gate in the current evidence scope. It can rise only in evidence-gated steps and can shrink immediately. Account capital, raw book depth, elapsed time or positive aggregate PnL cannot expand it.

Vertical scale means a larger q band for otherwise equal scope; horizontal scale means more concurrent opportunities/markets under shared constraints. Both capacity expansion and capacity reduction create new audited manifest/evidence state.
