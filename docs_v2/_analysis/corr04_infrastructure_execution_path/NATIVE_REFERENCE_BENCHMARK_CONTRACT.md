# Native Reference Benchmark Contract

`STATUS: REFERENCE ONLY — NOT PROMOTED`

Native runs the same production binary, config, source/transport semantics, connections, resource limits where possible, observability, secret scope and workload on the same host/kernel. It must not gain by removing TLS, feed checks, Recorder evidence, Risk, logging required for correctness, firewall or least privilege.

Compare semantic parity first, then feed/application RTT, EventToSend stages, scheduler/resource tails, reconnect, state age and Recorder effects. Disclose irreducible namespace/filesystem/supervision differences.

Native deployment promotion would additionally require material end-to-end capture/economic value, no reliability/security regression, reproducible provisioning/update/rollback, client supportability and explicit approval. A faster reference result alone leaves Docker canonical.
