# Infrastructure Experiment Design

`STATUS: PREDECLARED EVIDENCE CONTRACT`

Before observing results, specify hypothesis, baseline/treatment, exact changed variable, population/scope/regimes, one primary metric, guardrails, alignment/clock validity, exclusions, minimum support, uncertainty, stop rule and go/hold/reject interpretation.

Primary examples: matched-event arrival lead, state age at send, EventToSend P99 or scoped FullRouteCompletionRate. Guardrails include gaps/reorder/duplicates, invalid state, reconnect/outage, CPU/memory/disk/network, Recorder P0/P1, `UNKNOWN`, Recovery, account/reconciliation progress, readiness and security.

Use simultaneous paired observation for feeds where possible. Compare volatility, update rate, opportunity distribution, time-of-day and route regimes; report counts and tails. Two profiles cannot execute the same opportunity on one account. Later Micro-live uses preauthorized alternating intervals or fully isolated accounts and discloses confounding.

Incremental cost includes host/node/storage/bandwidth and quantifiable operations/security burden. Report negative and inconclusive evidence. Reproduction binds `RunManifest`, `FeedProfileId`, `InfraProfileId`, source/node/kernel/container/CPU profile and artifact hashes.
