# Speculative / Canonical Truth Boundary

`INVARIANT: SPECULATIVE IS NEVER ECONOMIC TRUTH`

| State/effect | Canonical lane | Speculative lane |
|---|---|---|
| `BookState`, `AccountState`, `OrderState` | may mutate through owned reducers | forbidden |
| `FillLedger`, Inventory, Reservations, PnL | actual exchange/account evidence only | forbidden |
| Recovery/Reconciliation | Execution-owned canonical evidence | forbidden |
| Opportunity/forecast | canonical IDs/counts after canonical state | separate research IDs/counts |
| Risk-increasing effect/sign/send | validated canonical plan only | forbidden |
| structural/pure preparation | allowed | allowed behind fingerprint/parity |

If schemas cannot safely encode epistemic class, speculative RAW uses a linked research dataset rather than silently expanding frozen canonical schemas. Canonical state stays correct when speculative data changes, reorders, duplicates, disappears, disconnects or arrives late.
