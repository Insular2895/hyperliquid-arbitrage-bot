# OPEN Classification Decision Tree

1. Canonical source/current higher authority resolves the question → `SOURCE_RESOLVED`.
2. It asks what an external system currently does → `EXTERNAL_REVALIDATION`.
3. Data/benchmark/statistical evidence should select it → `CALIBRATED` or `LEARNED`.
4. Equivalent internal representation/algorithm can be selected by engineering → `IMPLEMENTATION_CHOICE`.
5. The capability is outside the current path → `DEFERRED`.
6. Multiple evidence-eligible choices materially alter intended policy → `HUMAN_POLICY_DECISION`.

Classification precedes escalation. One primary semantic owner is mandatory.
