# M4 to M5 Bounded Evidence Corridor

```text
M3 no-effect evidence
  -> pre-registered M4 plan
  -> bounded real-effect probes
  -> immutable actual outcomes
  -> complete/censored/stopped population
  -> promotion review
  -> M5 exact supported scope
```

Risk/incident/stop evidence branches to termination, reconciliation and possible demotion. M4 cannot alter its own market, mode, q, time, loss, exposure or stop envelope and is never unlimited continuous Live. M5 remains bounded, reversible and human-approved.
