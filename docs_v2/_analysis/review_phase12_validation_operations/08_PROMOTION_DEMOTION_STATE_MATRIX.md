# Promotion and Demotion State Matrix

| Trigger | Promotion | Safety contraction | Restore |
|---|---|---|---|
| new sufficient evidence | explicit exact-scope review only | none implied | signed decision |
| missing/stale/invalid evidence | forbidden | automatic where mandatory | new evidence plus review |
| incident/model drift | forbidden | scoped or shared demotion | fix, proof, explicit re-promotion |
| infra/exchange change | forbidden for affected scope | inherited authority removed | revalidation |
| q expansion | new evidence required | prior scope unchanged or contracted | explicit promotion |
| healthy recovery | none | clears current health blocker only | no maturity restoration |
| explicit re-promotion | allowed after all gates | — | audited exact scope |

Demotion may be automatic toward safety. Promotion, q/capital expansion and online model promotion are never automatic.
