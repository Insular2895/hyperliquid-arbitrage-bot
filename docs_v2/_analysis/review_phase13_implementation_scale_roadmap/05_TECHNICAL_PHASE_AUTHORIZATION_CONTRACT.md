# Technical Phase Authorization Contract

`PhaseExit(N)` proves the declared DoD. `Authorization(N+1)` is a separate human record binding commit, scope, prerequisites, non-scope, evidence and stops. `CapitalPermission` is the runtime intersection of validated scope, readiness and Risk; neither former record implies it.

- Phase 1 PASS can coexist with Phase 2 NOT AUTHORIZED.
- Phase 19 Shadow PASS can coexist with Phase 20 Micro-live NOT AUTHORIZED.
- Phase 20 M4 evidence does not automatically create M5.

Codex must stop at each phase exit and request the next explicit authorization.
