# Counterfactual versus Realized Economics

| Mode | Economic output | May enter realized accounting? |
|---|---|---|
| deterministic Formula/Replay | reconstructed or hypothetical | no |
| Simulator | predicted distribution / counterfactual | no |
| Shadow | would-have outcome under no action | no |
| Micro-live/Live actual | actual events after reconciliation | yes |

Predicted EV is frozen before attempt. Counterfactual profile comparisons retain model/fidelity/seed and cannot create actual fills. Realized PnL comes only from deduplicated exchange/account events and reconciled action buckets. Validation joins predicted and actual records without rewriting either side.

Differences are model error/economic attribution evidence, not accounting adjustments. Missing actual resolution remains unresolved/censored, never a simulated substitute.
