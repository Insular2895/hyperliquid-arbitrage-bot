# Calibration-to-Economics Mapping

| Calibrated evidence | Canonical consumer | Forbidden shortcut |
|---|---|---|
| arrival survival QF-048/QF-085 | Simulator feature/joint distribution | multiply final EV blindly |
| F/P/R/X completion forecast | `Π_exec` scenario mass | parallel completion-adjusted EV |
| Recovery success | R-branch sub-outcomes/operations | treat as route success or zero loss |
| QF-095/096 calibration | promotion/demotion evidence | PnL term |
| QF-100 economic lift | model promotion evidence | realized PnL |
| QF-101 model value | value after latency/ops in declared scope | subtract latency twice |
| QF-102 disagreement / QF-103 OOD / QF-104 confidence | support and uncertainty governance | arbitrary cash multiplier |

Calibration changes a versioned distribution or its authority. It does not append a headline probability as an extra multiplier or deduction.
