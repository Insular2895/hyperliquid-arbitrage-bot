# QF-085 / QF-093 Semantic Audit

| Formula | Type | Meaning | Forbidden reuse |
|---|---|---|---|
| QF-085 | probability/model output | edge survives arrival under infrastructure profile `s` | full completion, positive PnL or ROI |
| QF-086 | monetary comparison input | expected gross PnL difference between coherent profiles | independent survival/completion bonus |
| QF-087–091 | cost/value chain | incremental cost, net value and close accounting | repeated infra-cost deduction |
| QF-093 | diagnostic/accounting ratio | ratio of realized PnL sum to expected executable PnL sum in scope | completion or success probability |

QF-093 may be above one and is undefined/guarded when its denominator is invalid or zero; this alone demonstrates it is not a Bernoulli event probability. Its numerator and denominator use comparable scoped cohorts and are never used to rescale individual route outcomes without a separate validated model.
