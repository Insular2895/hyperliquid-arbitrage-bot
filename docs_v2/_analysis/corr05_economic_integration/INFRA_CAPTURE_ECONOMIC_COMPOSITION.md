# Infrastructure Capture Economic Composition

For each infrastructure profile, produce one coherent counterfactual distribution over opportunity survival, attempt selection and `Π_exec`, with matching population, policy, q/state support and evidence versions. Profile value is the difference between comparable expected economic outcomes minus incremental profile cost once.

QF-085 describes survival at arrival. QF-086–QF-091 provide the existing profile comparison chain. Actual FullRouteCompletionRate and reconciled PnL validate downstream outcomes. These signals may explain the same incremental value and therefore are not multiplied or added as separate bonuses.

`InfraLostPnL` and `RecoverablePnL` are attribution/evidence views of the same profile delta, not additional deductions or gains. Faster latency alone is insufficient; correctness, reliability, coverage, security, operations burden and uncertainty remain required.
