# Model-Demotion Economic Effect

Demotion invalidates the affected model authority immediately for new decisions. The system selects only a predeclared, versioned fallback whose label semantics, q/state support and economic distribution are valid in the current scope.

Consequences may include broader uncertainty, lower RAEV, smaller `Q_validated`, simpler ranking or no new risk. Demotion never reuses stale forecasts, invents favorable probabilities, expands capacity, changes actual truth or self-modifies a live model.

Operations record trigger, old/new artifact, support-domain change, affected candidates, capacity change and rollback/revalidation status. Prediction history remains immutable for honest calibration.
