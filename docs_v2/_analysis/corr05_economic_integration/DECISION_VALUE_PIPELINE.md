# Decision-Value Pipeline

```text
canonical state + exact route economics
-> E0 frozen candidate and q
-> survival/participant/latency evidence
-> Simulator joint Π_exec(q,state)
-> QF-056 EV + QF-059 P+ + tail measures
-> QF-063 external non-overlapping penalties
-> economic ranking / QF-075 objective
-> QF-076 all-gates validated capacity
-> immutable RiskDecision (permission)
-> Execution actual truth
-> Recovery/Reconciliation
-> disjoint Accounting ledgers
-> predicted-versus-realized validation
```

Prediction cannot grant permission, permission cannot claim execution, and execution events do not become accounting truth before reconciliation. Positive RAEV cannot override a denied Risk gate.
