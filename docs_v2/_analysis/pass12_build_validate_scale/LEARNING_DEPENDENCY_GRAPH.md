## Primary causal chain

```text
RAW DATA
  → POINT-IN-TIME NORMALIZED EVENTS
  → BOOK / ACCOUNT RECONSTRUCTION
  → DIRECTED ROUTE ECONOMICS
  → OPPORTUNITY + REJECT EPISODES
  → SURVIVAL / CORRECTION / CAPTURE LABELS
  → SIMPLE EMPIRICAL CHAMPION
  → OOS CALIBRATION + ECONOMIC LIFT
  → DECISION-FACING MODEL SUPPORT
```

No model claim may precede an observable, defined, labeled, recorded and validated target.

## Execution calibration

```text
REPLAY F0/F1 FORECASTS
        +
SHADOW PREDECLARED FORECASTS
        +
MICRO-LIVE ACTUAL ACKS / FILLS / FEES / SLIPPAGE / RECOVERY / PNL
        ↓
PREDICTED ↔ ACTUAL DATASET
        ↓
SIMULATOR / EXECUTION CALIBRATION
        ↓
RISK + SIZING SUPPORT
        ↓
Q_VALIDATED
```

Shadow proves real-time behavior without own causal fills. Micro-live supplies the missing intervention evidence.

## Maker chain

```text
MAKER INTENTS + ARRIVAL BOOK + QUEUE OBSERVABILITY
  → RESTING/CANCEL/TRADE/FILL/PARTIAL EPISODES
  → FILL SURVIVAL + TIME-TO-FILL + ADVERSE-SELECTION LABELS
  → SIMPLE MAKER BASELINE
  → F2 QUEUE CALIBRATION
  → MAKER SHADOW
  → MT PROBE
  → MT VALIDATION
  → MTT-SPECIFIC VALIDATION
```

ALO syntax is an external capability fact; it is not maker-model evidence.

## Capital chain

```text
MARKET ATLAS HISTORY
  + Q_VALIDATED
  + ACTUAL INVENTORY / RESERVATIONS
  + TERMINAL VIABILITY / EXIT EVIDENCE
        ↓
CAPITAL UTILITY
        ↓
PORTFOLIO ALLOCATION
        ↓
STAY ↔ BRIDGE / RELOCATION COMPARISON
        ↓
REALIZED FUTURE UTILIZATION + EXIT OUTCOME
```

Bridge cannot be learned from a single temporary edge. Strategy, Bridge, Rebalance, Recovery and Stay remain distinct actions and accounting classes.

## Infrastructure chain

```text
OPPORTUNITY SURVIVAL / CAPTURE EPISODES
  + SAME-EVENT SERVER BENCHMARK
  + ACTUAL DECISION/ARRIVAL LATENCY
        ↓
INFRALOSTPNL / RECOVERABLEPNL
        ↓
NETUPGRADEVALUE + INFRAROI + LCB GATE
        ↓
UPGRADE, HOLD, DOWNGRADE OR REJECT
```

Technical benchmarking may begin early; economic infrastructure promotion must wait for capture evidence.

## Bootstrap graph

```text
CONSERVATIVE RULE BASELINE
  → EARLY SAFE EVIDENCE
  → CALIBRATED CHALLENGER
  → COMPARISON
  → PROMOTE CHALLENGER OR RETAIN BASELINE
```

This resolves Risk↔model, Atlas↔capital, Sizer↔Simulator and Participants↔opportunity cycles without throwaway architecture. Baselines implement the final interfaces.
