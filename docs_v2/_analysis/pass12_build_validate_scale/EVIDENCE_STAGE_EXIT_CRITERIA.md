# PASS 12 — Evidence Stage Exit Criteria

DOCUMENTATION STATUS:
REBUILD IN PROGRESS

No elapsed time or capital balance completes a stage. Evidence sufficiency follows PASS 10 and remains scope-specific.

| Stage | Required evidence before exit | Stop / remain in stage | What the next stage receives |
|---:|---|---|---|
| 0 | Purpose, contracts, invariants, failures, formulas, owners, test plan and external gates are explicit | Critical ambiguity or unresolved authority | Implementable M0 scope |
| 1 | Ordered immutable RAW, checksums, quality fields, capacity/backpressure metrics and source coverage are usable | Undetected gaps, ambiguous chronology, critical Recorder loss | Admissible source dataset |
| 2 | Snapshot+diff reconstruction, metadata/fee/precision history and invalid-region handling are reproducible | Book divergence, silent repair, rule ambiguity, nondeterminism | Trusted point-in-time state |
| 3 | Versioned topology, legal fixed routes, reverse dependencies and basic Atlas support are reproducible | Invalid continuity, comparator confusion, future-data leakage | Candidate universe |
| 4 | NetConvert and route economics match golden/parity rules; opportunities/rejects are reproducible | Formula/fee/precision/depth mismatch or false edge | Labeled opportunity episodes |
| 5 | Same manifest yields same DecisionTrace/hash; no-lookahead and checkpoint parity pass | Any nondeterminism, invalid data, hidden clock/RNG | M2 research substrate |
| 6 | F0/F1 distributions and limitations are declared; mechanics match replay/micro fixtures in support | Deterministic point PnL claim, unmodeled mechanics, unsupported bias | Pre-live forecast distributions |
| 7 | Sustained same-Core live-input operation, complete traces and zero strategy effects; stability/readiness acceptable | State leak, stale book, incomplete evidence, account mutation | M3 real-time evidence |
| 8 | Join keys, predictions, actuals, slices, validity, guardrails and stopping rules predeclared | Post-hoc metric selection or unjoinable evidence | Auditable probe protocol |
| 9 | Simple baseline, temporal OOS, calibration, OOD/fallback and useful EconomicLift where decision-facing | No label, weak support, miscalibration or no lift | Validated competition features or conservative fallback |
| 10 | Every probe bounded, reconciled and reconstructible; no critical incident; actual fills/fees/slippage/recovery/PnL captured | UNKNOWN, recovery/reconcile/accounting failure, unsupported tail, security/ops failure | Real calibration data |
| 11 | TT predicted↔actual errors/tails within approved support; current Risk/ops/dependencies; explicit promotion | Sample/evidence insufficient, Q_validated unsupported, degradation | Narrow TT CapabilityManifest scope |
| 12 | TTT separately proves each leg, actual-output propagation, intermediate inventory, partial/failure/recovery and tails | Treating TT as TTT proof or unresolved three-leg exposure | Narrow TTT scope |
| 13 | Maker fill/time/partial/adverse/cancel/expiry evidence supports a calibrated baseline and queue fidelity | ALO-only claim, no realistic queue data, OOD | Maker forecast usable for probes |
| 14 | MT and MTT each pass maker, later-leg, recovery, predicted↔actual and Risk evidence | One maker mode generalized to another; uncalibrated queue/adverse risk | Narrow maker CapabilityManifest scope |
| 15 | Point-in-time Atlas, inventory, terminal viability, exits, size curves and capital utility are supported | Raw route count or balance treated as utility/capacity | Capital opportunity model |
| 16 | Shared-balance/depth/inventory/Risk constraints hold; complex allocator beats simple baseline robustly | Double allocation, unstable solution, no EconomicLift | Validated multi-opportunity allocation |
| 17 | STAY comparator, Bridge/Exit/Risk costs, hysteresis and realized destination utilization support positive relocation value | Transient edge, no future history, flip-flop, unsafe terminal | Separately validated relocation scope |
| 18 | New routes/markets/instances repeat required evidence and remain genuinely independent inside shared constraints | Hidden correlation/shared resources or lost support | Wider validated capability set |
| 19 | Next q band has size-dependent fill/slippage/impact/completion/CVaR/recovery/inventory support and current Q_validated | Capital-only justification or worsened actual calibration | Larger reversible size band |
| 20 | Same-event benchmark plus robust attributable InfraLostPnL/NetUpgradeValue/InfraROI evidence exceeds cost/risk gate | Faster ping without recoverable economics, instability or clock uncertainty | Validated infra profile or rejection |

Negative exits are valid outcomes: reject, remain, demote, shrink, revert or disable. They are retained as evidence.
