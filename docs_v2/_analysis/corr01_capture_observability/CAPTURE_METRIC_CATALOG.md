# CORR-01 — Capture Metric Catalog

DOCUMENTATION STATUS: CANONICAL METRIC SEMANTICS — IMPLEMENTATION NOT AUTHORIZED

## Entry contract

Every catalog row supplies: purpose; numerator; denominator; population/exclusions; unit; time basis/window; dimensions; source records; missing-data behavior; minimum sample; consumers; status; known bias. `Excl` means only the data-quality exclusions in `FUNNEL_DENOMINATOR_AND_POPULATION_RULES.md`; business-negative outcomes remain included.

Common requirements: `FunnelDefinitionVersion`, `MetricDefinitionVersion`, `RunMode`, `PopulationId`, `AS_OF`, raw numerator/denominator and validity are always emitted. Exact numeric thresholds/sample minima are `CALIBRATED` unless `1` is logically sufficient for a count.
