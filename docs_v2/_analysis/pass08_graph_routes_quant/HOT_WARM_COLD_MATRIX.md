# HOT / WARM / COLD Matrix

DOCUMENTATION STATUS:
REBUILD IN PROGRESS

HWC is a reversible compute/economic-relevance classification. It is neither topology nor Risk permission.

| Capability | HOT | WARM | COLD |
|---|---|---|---|
| Market awareness | full current awareness | full identity/current monitoring | known globally; never forgotten |
| Book state | full L2 needed by active routes | L2/basic depth for confirmation | cheap BBO/timestamp/minimal state |
| Feature computation | incremental execution/route feature set | basic plus confirmation features | bounded anomaly/promotion signals |
| Route computation | active affected routes, exact survivors | candidate/deeper validation | cheap structural/BBO awareness |
| Participant models | supported bounded forecasts | selected validation/research inference | normally off |
| Simulator readiness | current supported fast interface | deeper confirmation when promoted | not continuously expensive |
| Capital reachability | owned/near/productive region is strong input | adjacent/candidate/capital-near | distant or currently unproductive |
| Recorder | broad raw/essential coverage | broad | broad enough to detect change; not blind |
| Promotion | reachability, persistent Atlas change, Global Watcher anomaly, strategy need | confirmation/persistence/capital approach | anomaly/topology/liquidity/opportunity change |
| Demotion | sustained loss of relevance/capability | failed confirmation or sustained decline | n/a |
| Hysteresis | separate promote/demote evidence prevents churn | confirmation buffer | no invented numeric threshold |
| Cost | highest bounded compute | intermediate | lowest continuous compute |

## Locked rules

- Thresholds, windows and score weights are `CALIBRATED/LEARNED`; source examples are illustrative.
- HOT cannot override stale data, Risk, inventory, comparator, unsupported model or execution capability.
- COLD does not mean unknown or ignored. Global Watcher plus broad Recorder coverage preserve exploration.
- Capital movement may change reachability and tiers but never structural topology.
- Route Activation uses HWC and source-supported capability inputs; activation/deactivation is reversible.
