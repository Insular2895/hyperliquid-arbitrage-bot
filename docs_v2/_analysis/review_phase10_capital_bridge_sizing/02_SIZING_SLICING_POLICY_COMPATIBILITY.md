# Sizing / Slicing Policy Compatibility

Immediate single-order and temporally sliced execution of the same q can differ in arrival, survival, completion, inventory duration, Recovery, ES/CVaR and RAEV. Representation-only fragmentation proven economically equivalent needs no revalidation. Material timing/waiting/repricing/cancel/mode/horizon change requires affected distribution and Risk evidence to be revalidated. Same-time clips consume the same unchanged depth.
