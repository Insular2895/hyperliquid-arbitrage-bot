# Scientific Iteration Contract

Canonical lifecycle: `OBSERVE -> UNDERSTAND -> HYPOTHESIZE -> TEST -> MEASURE -> VALIDATE -> PROMOTE -> MONITOR -> DEMOTE/RESEARCH`.

The first six transitions create evidence, not permission. Promotion is an explicit authority-controlled transition to a versioned artifact and does not itself bypass the existing Shadow/Micro-live/Live gates. Monitoring can contract scope or request demotion; it cannot mutate a Live model, q, capital or Risk rule in place.

The loop retains failed/censored/negative outcomes and separates machine facts from interpretation. Detailed authority: [deep specification](../../deep-specs/strategy-research/01_SCIENTIFIC_ITERATION_LOOP.md).
