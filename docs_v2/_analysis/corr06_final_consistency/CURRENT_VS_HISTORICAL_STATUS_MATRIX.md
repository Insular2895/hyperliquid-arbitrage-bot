# Current versus Historical Status Matrix

| Document class | Status rule | Treatment |
|---|---|---|
| root README, `docs_v2/README`, REBUILD_PLAN, `_review/**` | current workflow authority | must say CORR-01..06 complete, human review next |
| CORR-01..05 final reports | historical report at its commit | old successor statements preserved |
| PASS16 final report | historical package-generation record | not rewritten as if CORR-06 existed then |
| CORR-04 external research | dated evidence snapshot | stale absence claim visibly superseded, original ledger retained |
| Masters/deep specs/registers | current semantic authority | targeted CORR-06 appendices and ownership clarification |
| legacy `docs/**` | historical/legacy reference | no edits, no switchover |

This prevents history rewriting while ensuring no current navigation sends a reviewer into an obsolete workflow.
