# ADR-011 — Counterfactual distributions

## Context

Le futur historique est incompatible avec une intervention non observée.
## Decision

Produire une distribution calibrée, avec fidélités F0–F4 déclarées.
## Alternatives considered

Backtest déterministe présenté comme vérité; agents complets immédiats.
## Why selected

Exprime l'incertitude et sépare mécanique de réponse.
## Consequences

Monte Carlo/calibration/confidence; capacité limitée par fidélité supportée.
## Status

PROPOSED FOR REVIEW — LOCKED principle.
## Sources

SRC-008, SRC-004 Formula Book.
