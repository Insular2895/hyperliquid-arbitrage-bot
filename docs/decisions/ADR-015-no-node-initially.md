# ADR-015 — No node initially unless ROI proves it

## Context

Un node a coût/complexité élevés et son avantage spot n'est pas démontré ici.
## Decision

Feed public initial, adapter node-compatible; activer seulement après ROI causal.
## Alternatives considered

Node obligatoire; ignorer toute compatibilité node.
## Why selected

Mesure avant coût et préserve l'évolutivité.
## Consequences

Benchmark feed age/capture; faits node/région revalidés officiellement.
## Status

PROPOSED FOR REVIEW — LOCKED initial / future evidence.
## Sources

SRC-002, SRC-008, SRC-006.
